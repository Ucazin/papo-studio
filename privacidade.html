Política de Privacidade — Papo Studio

Última atualização: 14 de outubro de 2026

1. O que é o Papo Studio

O Papo Studio é uma ferramenta pessoal de edição e publicação de vídeos curtos, operada pelo próprio dono (conta do GitHub Ucazin). Ela roda no computador dele e publica nos canais e perfis dele. Não é oferecida ao público e não tem cadastro de usuários.

2. Quais dados acessamos

  • YouTube (Google): o ID, o nome e a foto do canal conectado. Também pedimos permissão para enviar vídeos (youtube.upload) e para gerenciar os vídeos enviados pela ferramenta, por exemplo para mudar ou cancelar um agendamento (youtube). Não lemos comentários, inscritos, mensagens nem dados de outros canais.
  • Instagram e Facebook (Meta) e TikTok, quando conectados: o ID, o nome e a foto da conta, e a permissão para publicar vídeos ou enviá-los como rascunho.

3. Como usamos esses dados

Só para publicar ou agendar os vídeos que o dono aprovou, na conta que ele escolheu, e para mostrar o nome e a foto da conta na tela de aprovação, para evitar publicar na conta errada. Não usamos os dados para publicidade, não criamos perfis, não vendemos dados e não os usamos para treinar modelos de inteligência artificial.

4. Onde os dados ficam

Os tokens de acesso das contas ficam guardados só no computador do dono, cifrados pelo próprio Windows. Eles não são enviados a nenhum servidor nosso nem a banco de dados na nuvem. Os vídeos ficam no computador do dono até serem enviados à rede escolhida.

5. Compartilhamento

Não compartilhamos dados com terceiros. As informações só são enviadas à própria rede (Google/YouTube, Meta ou TikTok), e apenas para executar a publicação pedida.

6. Retenção e exclusão

Ao desconectar uma conta na ferramenta, o token dela é apagado do computador. O acesso também pode ser revogado a qualquer momento direto na rede:

  • Google/YouTube: myaccount.google.com/permissions
  • Facebook e Instagram: Configurações → Apps e sites
  • TikTok: Configurações e privacidade → Segurança → Apps e serviços com permissão

7. Serviços de API do Google e do YouTube

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

O Papo Studio usa os Serviços de API do YouTube. Ao conectar um canal, você concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

8. Contato

Dúvidas ou pedidos sobre esta política: github.com/Ucazin/papo-studio/issues.

9. Mudanças nesta política

Se esta política mudar, a nova versão será publicada nesta página com a data de atualização.
